# AGENTS.md — правила для AI-агентов

Это Obsidian-хранилище с учебными конспектами и материалами ТГАСУ. Файл описывает, как AI-агентам (Claude Code, Codex, Cursor, Copilot и др.) читать и изменять это хранилище.

## 2. Именование

- Одна дисциплина — одна папка внутри семестра.
- **Все работы именуются по шаблону `<Тип> N.md`** — без даты в имени; дата хранится в frontmatter в поле `created`:
  - `Лекция N.md` (несколько лекций — `Лекция N-M.md`);
  - `Практика N.md`;
  - `Практическая работа N.md`;
  - `Лабораторная работа N.md`.
- Даты в имени файла не дублируются — только в `created`.
- Названия папок и файлов — без опечаток. Правильно: «Теоретическая механика», «Безопасность жизнедеятельности».
- Вложения — в подпапке `attachments/` (или `Attachments/`) рядом с заметкой.

## 3. Формат заметки

Каждая заметка начинается с YAML frontmatter:

```yaml
---
created: YYYY-MM-DD
tags:
  - <Дисциплина>
  - <Семестр>
---
```

- `created` — дата создания/проведения работы в формате `YYYY-MM-DD`.
- Теги — только в frontmatter, не в теле заметки.
- Имя файла уже является заголовком — не дублируйте его отдельным `#`-заголовком.
- Разделы — `##`, подразделы — `###`.
- Формулы — LaTeX: блочные `$$ ... $$`, встроенные `$ ... $` (см. `Agent/Skills/Math.md`).
- Callout-блоки Obsidian: `> [!Определение]`, `> [!Теорема]`, `> [!Задача]` и т. п.
- Списки: `-` для маркированных, `1.` для нумерованных; вложенность — 3–4 пробела.

## 4. Ссылки

- Wiki-ссылки: `[[путь/к/заметке|Отображаемый текст]]`.
- Изображения: `![[путь/к/изображению]]`.
- При переименовании файла или папки обновляйте все ссылки на них.
- Не создавайте «битые» ссылки на несуществующие заметки.

## 5. Теги

Используйте существующие теги:

- Дисциплины: `History`, `Mathematics`, `Physics`, `TheoreticalMechanics`, `OOP`, `OS`, `Philosophy`, `LifeSafety`, `English`, `FundamentalsOfVehicleDesign`.
- Семестры: `SecondSemester`, `ThirdSemester`.
- Служебные: `Base`, `Agent`.

Новые теги — только при необходимости и в том же стиле (CamelCase, английский).

## 6. Скиллы

Скиллы лежат в `Agent/Skills/`. Перед работой с дисциплиной загляните в соответствующий скилл:

| Скилл | Для чего |

| `Math.md` | LaTeX, формулы, дроби, векторы, единицы |
| `Physics.md` | физика: величины, единицы, схемы |
| `History.md` | даты, имена, таблицы правителей |
| `OOP.md` | C++/ООП: классы, код |
| `OS.md` | команды, скриншоты, отчёты |
| `Philosophy.md` | определения, цитаты |
| `LifeSafety.md` | нормативы, расчёты |
| `English.md` | термины, примеры |
| `Automotive.md` | узлы автомобиля, схемы |

## 7. Правила редактирования

- Не создавайте новые файлы без явной просьбы пользователя — правьте существующие.
- Не удаляйте чужой контент; исправляйте ошибки точечно.
- Сохраняйте авторский стиль, смысл и структуру. Правьте только явные опечатки, пунктуацию и оформление.
- Не выдумывайте факты, формулы и даты. При сомнении оставляйте `> [!TODO]` и не выдавайте догадку за факт.
- Перед массовыми переименованиями и переносами — согласуйте с пользователем.
- После правок проверяйте, что wiki-ссылки не сломались.

## 8. Приоритеты

1. Корректность фактов и формул.
2. Сохранность существующего контента.
3. Единообразие оформления.
4. Минимальные и обратимые изменения.
