# Math — правила оформления математики

Используй LaTeX для всех формул. Этот файл — обязательный стандарт для заметок с математикой.

## Блочные формулы
Выносятся отдельным блоком и не смешиваются с текстом:

$$
a^2 + b^2 = c^2
$$

## Встроенные формулы
Внутри текста — в одинарных долларах: по условию $\omega = 0$.

## Основные правила
- Умножение — `\cdot`, не `*`: $2 \cdot 3 = 6$.
- Дроби — `\frac{a}{b}`: $\frac{1}{2}$.
- Корни — `\sqrt{x}`, `\sqrt[n]{x}`.
- Векторы — `\vec{F}` (или `\mathbf{F}` для жирного начертания).
- Суммы и интегралы — `\sum_{k=1}^{n}`, `\int_{a}^{b}`.
- Пределы — `\lim_{x \to 0}`.
- Греческие буквы — `\alpha`, `\beta`, `\gamma`, `\omega`, `\Delta`.
- Индексы: нижний — `F_{kx}`, верхний — `x^2`.
- Десятичная запятая — `{,}`, чтобы не было пробела: $1{,}5$.
- Единицы измерения — через `\text{}`: $10\ \text{м/с}^2$.
- Русские обозначения — `\text{}`: $\text{ИФС}$.

## Пример

Кинетическая энергия материальной точки:

$$
E_k = \frac{m v^2}{2}
$$
