# OOP — правила оформления

- Код — в блоках с языком:

```cpp
class Tovar {
public:
    void displayInfo() const;
};
```

- Классы — `class`, `struct`; методы — с возвращаемым типом.
- Принципы: инкапсуляция, наследование, полиморфизм.
- Практическая: задание → решение → вывод; ключевые моменты — таблицей.
