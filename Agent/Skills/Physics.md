# Physics — правила оформления

- Все формулы — LaTeX (см. `Math.md`).
- Векторы — `\vec{v}`, `\vec{F}`; модуль — $|\vec{v}|$ или $v$.
- Единицы — через `\text{}`: $10\ \text{м/с}^2$.
- Производные по времени — точка: `\dot{x}`, `\ddot{x}`.
- Схемы и графики — изображениями `![[attachments/...]]`.
- Лабораторная: цель → таблица измерений → формула расчёта → погрешность → вывод.
- Коллоквиум: вопрос → краткий ответ → формула.
