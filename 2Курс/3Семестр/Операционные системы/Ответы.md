**Если тормозит ПК (PowerShell от админа):**
```powershell
# Топ процессов по памяти
Get-Process | Sort-Object WorkingSet64 -Descending | Select-Object -First 10 Name, Id, @{n='RAM_MB';e={[math]::Round($_.WorkingSet64/1MB,1)}}

# Нагрузка CPU и память в реальном времени
Get-Counter '\Processor(_Total)\% Processor Time','\Memory\Available MBytes' -SampleInterval 2 -MaxSamples 15
```
Если подозрение на повреждение системы:
```powershell
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
```

**Если не открывается сайт:**
```powershell
Get-NetAdapter                 # адаптер должен быть Up
Get-NetIPConfiguration         # IP и шлюз; 169.254.* — плохо
Test-Connection <шлюз> -Count 3
Test-Connection 8.8.8.8 -Count 3
Resolve-DnsName example.com    # проверка DNS
ipconfig /flushdns             # очистить DNS-кэш
Test-NetConnection example.com -Port 443
Test-NetConnection 8.8.8.8 -TraceRoute
```

**Как читать результат:**
- Шлюз не пингуется — проблема в локальной сети/Wi-Fi/кабеле.
- Шлюз пингуется, 8.8.8.8 нет — провайдер или роутер.
- IP пингуется, имя сайта не resolve — DNS.
- Всё пингуется, но сайт не открывается — браузер, прокси или блокировка порта.

Сброс сети, если совсем ничего:
```powershell
netsh winsock reset
```
Потом перезагрузка.
