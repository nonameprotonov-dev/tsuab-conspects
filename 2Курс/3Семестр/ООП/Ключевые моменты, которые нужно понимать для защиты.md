| Работа  | Что важно знать                                                                                                                                                                                                                             |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **PR1** | Класс — это «чертёж» объекта. Объект — экземпляр класса. Приватные поля доступны только через публичные методы (инкапсуляция).                                                                                                              |
| **PR2** | Определение методов вне класса улучшает читаемость и разделение кода. `name`, `employee_id`, `salary` обычно закрытые — их нельзя менять напрямую.                                                                                          |
| **PR3** | Интерфейс (`Tovar.h`) — что делает класс; реализация (`Tovar.cpp`) — как он это делает; подключение (`main.cpp`) — использование. Ввод — `cin.ignore()` перед `getline`. Дозапись — `ios_base::app`.                                        |
| **PR4** | Конструктор — создаёт и инициализирует объект, имя = имя класса, нет возвращаемого типа. Деструктор — `~Tovar()`, освобождает ресурсы, вызывается автоматически.                                                                            |
| **PR5** | Наследник получает доступ к `public`/`protected` полям. При переопределении `displayInfo()` нужно либо вызвать `Tovar::displayInfo()`, либо полностью заменить.                                                                             |
| **PR6** | Оператор-метод вызывается через объект (`a + b`). Дружественная функция даёт доступ к `private`. `<<` и `>>` **нельзя** перегрузить как методы, потому что объект стоит справа. Виртуальный деструктор обязателен при полиморфном удалении. |
