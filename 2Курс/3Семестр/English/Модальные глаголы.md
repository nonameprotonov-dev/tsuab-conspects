> [!abstract] Суть
> Модальные глаголы выражают **отношение говорящего к действию**: возможность, необходимость, разрешение, вероятность, совет. Сами по себе действие не называют — работают в паре с инфинитивом смыслового глагола.

## Общие свойства

- Не изменяются по лицам и числам (нет `-s` в 3 л. ед. ч.): *He **can** swim*, не ~~cans~~.
- Не требуют вспомогательного `do/does/did` в вопросах и отрицаниях: *Can you...?*, *He cannot...*
- Перед ними ставится частица **not** (слитно или раздельно): *cannot, mustn't, shouldn't*.
- После них — **инфинитив без to** (кроме *ought to, have to, be able to*).
- Не имеют форм инфинитива, причастия, герундия.
- Не имеют будущего времени → заменяются эквивалентами.

## Сводная таблица

| Глагол                | Значение                                 | Пример             |
| --------------------- | ---------------------------------------- | ------------------ |
| **can / could**       | умение, возможность, разрешение          | I can drive.       |
| **may / might**       | разрешение, вероятность                  | It may rain.       |
| **must**              | обязанность, уверенность                 | You must stop.     |
| **have to**           | вынужденность (внешняя)                  | I have to work.    |
| **should / ought to** | совет, рекомендация                      | You should rest.   |
| **will / would**      | воля, привычка, вежливость               | Would you help?    |
| **shall**             | предложение, долженствование (формально) | Shall we go?       |
| **need**              | необходимость (чаще в отриц./вопр.)      | You needn't worry. |
| **dare**              | смелость (чаще в отриц./вопр.)           | He daren't say it. |

## Can / Could

> [!info] Основные значения
> - **Способность:** *She can speak French.*
> - **Возможность (объективная):** *You can buy tickets online.*
> - **Разрешение (неформальное):** *Can I open the window?*
> - **Запрет:** *You can't park here.*
> - **Просьба:** *Can you help me?*

**Could** — прошедшее от *can* + вежливая/гипотетическая форма:
- *When I was young, I could run fast.* (прошлая способность)
- *Could you repeat that?* (вежливая просьба)
- *It could be true.* (слабая вероятность)

> [!warning] Ошибки
> - В прошлом для разового успеха — **не** could, а *was able to / managed to*: *He **was able to** escape* (не ~~could escape~~).
> - Отрицание прошедшего: *couldn't* — общая неспособность, *wasn't able to* — конкретный случай.

## May / Might

> [!info] Значения
> - **Разрешение (формальное):** *May I come in?*
> - **Вероятность (may > might):** *It may snow tomorrow. / It might snow.*
> - **Пожелание (архаично):** *May you be happy!*

- **might** — более слабая вероятность, чаще в гипотетике: *If I had time, I might travel.*
- Отрицание вероятности: *may not / might not*.

## Must / Have to

| | **Must** | **Have to** |
|---|---|---|
| Источник | говорящий (внутренняя обязанность) | внешние обстоятельства |
| Пример | *You must see a doctor.* (я так считаю) | *I have to wear a uniform.* (правила) |
| Отрицание | **mustn't** = запрет | **don't have to** = не обязательно |

> [!note] Уверенность
> *Must* также = логический вывод: *He must be tired* (наверное, устал). Отрицание вывода — **can't**: *He can't be tired* (не может быть).

> [!warning] Формы
> *Must* не имеет прошедшего/будущего → используем *had to / will have to*.

## Should / Ought to

- **Совет:** *You should see this film.*
- **Ожидание/вероятность:** *The train should arrive at 5.*
- **Критика (с perfect):** *You should have called.* (следовало позвонить)
- *Ought to* — формальнее, с частицей **to**.

## Will / Would

- **Will** — воля, обещание, привычка в настоящем: *He'll help you. / She'll sit for hours reading.*
- **Would** — вежливость, гипотетика, прошлая привычка: *Would you mind? / I would go if I could. / We would often walk there.*
- **Won't** — упорное нежелание: *The door won't open.*

## Shall

- Предложение/вопрос: *Shall we dance?*
- Формальное долженствование в документах: *The tenant shall pay rent.*
- В современном разговорном вытесняется *will/should*.

## Need / Dare

> [!info] Особые случаи
> - **Need** как модальный — только в отрицании/вопросе: *You needn't come. / Need I say more?* → 3 л. ед. ч. без `-s`.
> - Как обычный глагол: *He needs to go.*
> - **Dare** — аналогично: *He daren't tell her. / Dare you ask?* vs *He doesn't dare to ask.*

## Модальные + Perfect Infinitive (have + V3)

> [!important] Ключевая тема — оттенки прошлого

| Конструкция | Значение | Пример |
|---|---|---|
| **must have + V3** | уверенность в прошлом | *She must have left already.* |
| **can't / couldn't have + V3** | уверенность, что не было | *He can't have said that.* |
| **may / might have + V3** | вероятность в прошлом | *They might have missed the bus.* |
| **could have + V3** | была возможность, но не использована | *You could have told me.* |
| **should / ought to have + V3** | следовало, но не сделано (упрёк) | *I should have studied harder.* |
| **shouldn't have + V3** | не следовало делать | *You shouldn't have lied.* |
| **needn't have + V3** | сделал зря (не нужно было) | *You needn't have cooked.* |
| **would have + V3** | гипотетика (3-й conditional) | *I would have come if invited.* |

## Эквиваленты (заменители)

| Модальный | Эквивалент        | Пример                   |
| --------- | ----------------- | ------------------------ |
| can       | be able to        | I will be able to help.  |
| must      | have to / be to   | I had to leave early.    |
| may       | be allowed to     | We were allowed to stay. |
| need      | have to / need to | Do you need to go?       |

## Типичные ошибки

> [!failure] Частые ловушки
> - ~~He cans swim~~ → *He can swim*
> - ~~I must to go~~ → *I must go*
> - ~~You don't must~~ → *You mustn't / You don't have to*
> - ~~I can to do it~~ → *I can do it*
> - ~~She shoulds rest~~ → *She should rest*
> - ~~must have went~~ → *must have gone*
