# Конспект лекций: Кинематика материальной точки

## 1. Основы кинематики

### 1.1. Модели и системы отсчета

- **Материальная точка** — тело, размерами и формой которого в условиях данной задачи можно пренебречь, считая всю его массу сосредоточенной в одной точке.
- **Тело отсчета** — тело, относительно которого определяется положение других тел.
- **Система отсчета** — совокупность системы координат (связанной с телом отсчета) и прибора для измерения времени (часов).
- **Радиус-вектор** — вектор$\vec{r}$, проведенный из начала координат в точку нахождения тела. Координатный способ задания: 
	$\vec{r} = x\vec{i} + y\vec{j} + z\vec{k}$
    где$\vec{i}, \vec{j}, \vec{k}$— единичные орты координатных осей.
- **Траектория** — линия, которую описывает тело при движении.

### 1.2. Путь и перемещение

- **Перемещение ($\Delta\vec{r}$)** — вектор, соединяющий начальное положение тела с конечным.
   $\Delta\vec{r} = \vec{r} - \vec{r}_0$
- **Путь ($S$)** — скалярная величина, равная длине траектории.$S \ge 0$.
    - Соотношение пути и перемещения:
        - При прямолинейном движении:$S = |\Delta\vec{r}|$
        - При криволинейном движении:$S > |\Delta\vec{r}|$

## 2. Основные кинематические характеристики

### 2.1. Скорость

- **Средняя скорость ($\vec{v}_{ср}$)** — векторная величина, равная отношению перемещения ко времени, за которое оно произошло:
   $\vec{v}_{ср} = \frac{\Delta\vec{r}}{\Delta t}$
- **Мгновенная скорость ($\vec{v}$)** — скорость в данный момент времени (в данной точке траектории). Направлена по касательной к траектории.
   $\vec{v} = \lim_{\Delta t \to 0} \frac{\Delta\vec{r}}{\Delta t} = \frac{d\vec{r}}{dt} = \dot{\vec{r}}$
    В координатном виде:$\vec{v} = v_x\vec{i} + v_y\vec{j} + v_z\vec{k} = \frac{dx}{dt}\vec{i} + \frac{dy}{dt}\vec{j} + \frac{dz}{dt}\vec{k}$
- **Связь с путем:** Модуль мгновенной скорости равен производной пути по времени:$v = \frac{dS}{dt}$.

### 2.2. Ускорение

- **Ускорение ($\vec{a}$)** — векторная физическая величина, характеризующая быстроту изменения скорости.
   $\vec{a} = \lim_{\Delta t \to 0} \frac{\Delta\vec{v}}{\Delta t} = \frac{d\vec{v}}{dt} = \dot{\vec{v}}$
- **Замедленное движение:** Если вектор скорости и вектор ускорения направлены противоположно ($\vec{v} \uparrow\downarrow \vec{a}$), скорость уменьшается.
- **Ускоренное движение:** Если вектор скорости и вектор ускорения направлены одинаково ($\vec{v} \uparrow\uparrow \vec{a}$), скорость растет.

## 3. Прямолинейное движение

При прямолинейном движении траектория — прямая линия. Достаточно одной оси координат (например, OX).

### 3.1. Равномерное движение ($\vec{a} = 0$)

Скорость постоянна по модулю и направлению ($v = const$).

- **Уравнение скорости:**$v_x = v_{0x} = const$
- **Уравнение координаты:**$x = x_0 + v_{0x}t$
- **Уравнение перемещения:**$\Delta r_x = x - x_0 = v_{0x}t$
- **Путь:**$S = |v_{0x}| t$

### 3.2. Равнопеременное движение ($\vec{a} = const$)

Движение с постоянным ускорением. Делится на равноускоренное и равнозамедленное.

- **Уравнение скорости:**$v_x = v_{0x} + a_x t$
- **Уравнение координаты:**
   $x = x_0 + v_{0x}t + \frac{a_x t^2}{2}$
- **Уравнение перемещения:**
   $\Delta r_x = v_{0x}t + \frac{a_x t^2}{2}$
- **Путь:**$S = |v_{0x}t + \frac{a_x t^2}{2}|$
- **Правило знаков:**
    - При **равноускоренном** движении знаки$v_0$и$a$в скалярном уравнении **совпадают**.
    - При **равнозамедленном** движении знаки$v_0$и$a$в скалярном уравнении **противоположны**.

---

## 4. Криволинейное движение

При криволинейном движении скорость всегда направлена по касательной к траектории. Полное ускорение раскладывается на две составляющие.

- **Тангенциальное (касательное) ускорение ($\vec{a}_\tau$)** — характеризует изменение скорости по **величине**. Направлено по касательной к траектории.
   $a_\tau = \frac{dv}{dt}$
- **Нормальное (центростремительное) ускорение ($\vec{a}_n$)** — характеризует изменение скорости по **направлению**. Направлено по радиусу к центру кривизны траектории.
   $a_n = \frac{v^2}{R}$
    где$R$— радиус кривизны траектории в данной точке.
- **Полное ускорение:**
   $\vec{a} = \vec{a}_\tau + \vec{a}_n$
   $a = \sqrt{a_\tau^2 + a_n^2}$
- **Частные случаи:**
    - Прямолинейное движение:$R \to \infty \Rightarrow a_n = 0, a = a_\tau$.
    - Равномерное движение по окружности:$a_\tau = 0, a = a_n$.

## 5. Вращательное движение. Кинематика

Для описания вращения твердого тела используются угловые величины.

### 5.1. Угловые характеристики

- **Угловое перемещение ($\Delta\vec{\varphi}$)** — вектор, модуль которого равен углу поворота радиус-вектора. Направление определяется **правилом буравчика (правого винта)**. Вектор направлен вдоль оси вращения.
    - Связь с длиной дуги:$\Delta l = \Delta\varphi \cdot R$, где$\Delta\varphi$выражен в **радианах**.
    - Полный оборот:$\Delta\varphi_{полн} = 2\pi$рад.
- **Угловая скорость ($\vec{\omega}$)** — вектор, характеризующий быстроту изменения угла поворота.
   $\vec{\omega} = \lim_{\Delta t \to 0} \frac{\Delta\vec{\varphi}}{\Delta t} = \frac{d\vec{\varphi}}{dt}$
    Направлена вдоль оси вращения (так же, как$\Delta\vec{\varphi}$). Единица измерения: рад/с.
- **Период ($T$)** — время одного полного оборота.
   $T = \frac{t}{N}$
- **Частота ($\nu$)** — число оборотов в единицу времени.
   $\nu = \frac{N}{t} = \frac{1}{T}$
    Единица измерения: Герц (Гц) или с$^{-1}$.

### 5.2. Связь линейных и угловых величин

- Связь линейной и угловой скорости (модули):
   $v = \omega R$
    В векторном виде:$\vec{v} = [\vec{\omega} \times \vec{R}]$
- Связь ускорений (для вращения по окружности):
    - Тангенциальное:$a_\tau = \varepsilon R$
    - Нормальное:$a_n = \omega^2 R = \frac{v^2}{R}$

### 5.3. Угловое ускорение

- **Угловое ускорение ($\vec{\varepsilon}$)** — вектор, характеризующий быстроту изменения угловой скорости.
   $\vec{\varepsilon} = \lim_{\Delta t \to 0} \frac{\Delta\vec{\omega}}{\Delta t} = \frac{d\vec{\omega}}{dt}$
- **Направление:**
    - При равноускоренном вращении:$\vec{\omega} \uparrow\uparrow \vec{\varepsilon}$
    - При равнозамедленном вращении:$\vec{\omega} \uparrow\downarrow \vec{\varepsilon}$

### 5.4. Уравнения равнопеременного вращения ($\varepsilon = const$)

Аналогичны уравнениям прямолинейного движения.

| Физическая величина              | Равноускоренное вращение                      | Равнозамедленное вращение                      |
| -------------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| **Угловая скорость**               |$\omega = \omega_0 + \varepsilon t$       |$\omega = \omega_0 - \varepsilon t$       |
| **Угловое перемещение (угол)**     |$\varphi = \varphi_0 + \omega_0 t + \frac{\varepsilon t^2}{2}$|$\varphi = \varphi_0 + \omega_0 t - \frac{\varepsilon t^2}{2}$|

## 6. Частные случаи движения в поле тяжести

Движение под действием силы тяжести происходит с постоянным ускорением$\vec{g}$, направленным вертикально вниз.$g \approx 9.81 \text{ м/с}^2$.

### 6.1. Вертикальное движение

- **Свободное падение ($v_0 = 0$):**
    - Время падения с высоты$H$:$t = \sqrt{\frac{2H}{g}}$
    - Скорость в момент падения:$v = \sqrt{2gH}$
- **Падение с начальной скоростью$v_0$вниз:**
    - Скорость:$v = v_0 + gt$
    - Координата:$y = H - v_0 t - \frac{gt^2}{2}$
- **Тело, брошенное вертикально вверх:**
    - Время подъема на макс. высоту:$t_{под} = \frac{v_0}{g}$
    - Максимальная высота подъема:$H = \frac{v_0^2}{2g}$
    - Время подъема равно времени падения:$t_{под} = t_{пад}$
    - Модуль конечной скорости равен модулю начальной:$v_{пад} = v_0$

### 6.2. Горизонтальное движение

Тело брошено горизонтально с высоты$H$со скоростью$v_0$.
- Движение по оси X (горизонталь) — равномерное.
- Движение по оси Y (вертикаль) — свободное падение.
- **Время падения:**$t = \sqrt{\frac{2H}{g}}$(зависит только от высоты)
- **Дальность полета:**$L = v_0 t = v_0 \sqrt{\frac{2H}{g}}$
- **Скорость в любой момент:**$v = \sqrt{v_0^2 + (gt)^2}$

### 6.3. Движение под углом$\alpha$к горизонту

Тело брошено со скоростью$v_0$под углом$\alpha$к горизонту.
- Проекции начальной скорости:$v_{0x} = v_0\cos\alpha$,$v_{0y} = v_0\sin\alpha$
- Движение по оси X — равномерное.
- Движение по оси Y — равнопеременное с ускорением$-g$.
- **Время подъема:**$t_{под} = \frac{v_0 \sin\alpha}{g}$
- **Полное время полета:**$T = 2t_{под} = \frac{2v_0 \sin\alpha}{g}$
- **Максимальная высота:**$H = \frac{v_0^2 \sin^2\alpha}{2g}$
- **Дальность полета:**$L = \frac{v_0^2 \sin 2\alpha}{g}$(максимальна при$\alpha = 45^\circ$)
- Траектория — парабола.
