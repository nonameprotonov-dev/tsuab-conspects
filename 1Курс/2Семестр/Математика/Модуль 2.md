# 📑 ШПАРГАЛКА: ФУНКЦИИ НЕСКОЛЬКИХ ПЕРЕМЕННЫХ (ФНП)

## 1. Основные понятия и приращения

- **Определение ФНП ($z=f(x,y)$):** Закон, по которому каждой паре чисел $(x,y)$ из множества $D$ ставится в соответствие единственное значение $z$.
    
- **Область определения ($D$):** Множество точек плоскости, где функция существует.
    
    - _Замкнутая:_ включает свои границы (например, $x^2 + y^2 \le 4$ — круг с окружностью).
        
    - _Незамкнутая:_ не включает границы (например, $y > x^2$).
        
- **Приращения функции в точке $(x_0, y_0)$:**
    
    - **Частное по $x$:** $\Delta_x z = f(x_0 + \Delta x, y_0) - f(x_0, y_0)$.
        
    - **Частное по $y$:** $\Delta_y z = f(x_0, y_0 + \Delta y) - f(x_0, y_0)$.
        
    - **Полное приращение:** $\Delta z = f(x_0 + \Delta x, y_0 + \Delta y) - f(x_0, y_0)$.
        

## 2. Частные производные

- **Определение:** Производные по одной переменной, при условии, что остальные переменные считаются константами (фиксируются).
    
    $$f'_x = \lim_{\Delta x \rightarrow 0} \frac{\Delta_x z}{\Delta x}; [cite_start]\quad f'_y = \lim_{\Delta y \rightarrow 0} \frac{\Delta_y z}{\Delta y}$$
    
- **Механический смысл:** Скорость изменения функции в точке $(x_0, y_0)$ в направлении соответствующей координатной оси ($OX$ или $OY$).
    

## 3. Полный дифференциал и приближенные вычисления

- **Формула полного дифференциала ($dz$):**
    
    $$dz = \frac{\partial f(x_0,y_0)}{\partial x}dx + \frac{\partial f(x_0,y_0)}{\partial y}dy, \quad \text{где } dx = \Delta x, \, dy = \Delta y$$
    
- **Условия дифференцируемости:**
    
    - _Необходимое:_ существование частных производных.
        
    - _Достаточное:_ непрерывность частных производных в исследуемой точке.
        
- **Приближенные вычисления (при малых $\Delta x, \Delta y$):**
    
    $$f(x_0 + \Delta x, y_0 + \Delta y) \approx f(x_0, y_0) + \frac{\partial f(x_0,y_0)}{\partial x}\Delta x + \frac{\partial f(x_0,y_0)}{\partial y}\Delta y$$
    

## 4. Дифференцирование сложных функций

- **Случай 1: $z = f(x,y)$, где $x = \varphi(t), y = \psi(t)$** (полная производная по $t$):
    
    $$\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}$$
    
- **Случай 2: $z = f(x,y,t)$, где $x = \varphi(t), y = \psi(t)$:**
    
    $$\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt} + \frac{\partial z}{\partial t}$$
    
- **Случай 3: $z = f(x,y)$, где $y = \psi(x)$** (полная производная по $x$):
    
    $$\frac{dz}{dx} = \frac{\partial z}{\partial x} + \frac{\partial z}{\partial y}\frac{dy}{dx}$$
    
- **Случай 4: $z = f(x,y)$, где $x = \varphi(t,\tau), y = \psi(t,\tau)$:**
    
    $$\frac{\partial z}{\partial t} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial t} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial t}; [cite_start]\quad \frac{\partial z}{\partial \tau} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial \tau} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial \tau}$$
    

## 5. Дифференцирование неявных функций

- **Функция одной переменной $F(x,y) = 0$:**
    
    $$\frac{dy}{dx} = -\frac{\frac{\partial F}{\partial x}}{\frac{\partial F}{\partial y}} \quad \left(\text{при } \frac{\partial F}{\partial y} \neq 0\right)$$
    
- **Функция двух переменных $F(x,y,z) = 0$:**
    
    $$\frac{\partial z}{\partial x} = -\frac{\frac{\partial F}{\partial x}}{\frac{\partial F}{\partial z}}; [cite_start]\quad \frac{\partial z}{\partial y} = -\frac{\frac{\partial F}{\partial y}}{\frac{\partial F}{\partial z}} \quad \left(\text{при } \frac{\partial F}{\partial z} \neq 0\right)$$
    

## 6. Производные высших порядков

- **Определение:** Частные производные от частных производных 1-го порядка. Обозначения: $\frac{\partial^2 z}{\partial x^2}$ (чистая), $\frac{\partial^2 z}{\partial x \partial y}$ (смешанная).
    
- **Теорема о равенстве смешанных производных:** Если смешанные производные непрерывны в области $D$, то они равны между собой и не зависят от порядка дифференцирования:
    
    $$\frac{\partial^2 f}{\partial x \partial y} = \frac{\partial^2 f}{\partial y \partial x}$$
    

## 7. Элементы теории скалярного поля

- **Линия / Поверхность уровня:** Множество точек плоскости или пространства, в которых функция принимает постоянное значение ($U(x,y) = \text{const}$).
    
- **Градиент ($\text{grad } U$):** Вектор, координатами которого являются частные производные функции:
    
    $$\text{grad } U = \frac{\partial U}{\partial x}\vec{i} + \frac{\partial U}{\partial y}\vec{j} + \frac{\partial U}{\partial z}\vec{k} = \left( \frac{\partial U}{\partial x}; \frac{\partial U}{\partial y}; \frac{\partial U}{\partial z} \right)$$
    
- **Свойства градиента:**
    
    1. Указывает направление **максимального роста** скалярного поля.
        
    2. Модуль градиента ($|\text{grad } U| = \sqrt{(U'_x)^2 + (U'_y)^2 + (U'_z)^2}$) численно равен **наибольшей скорости** изменения поля в данной точке.
        

### 💡 Шпаргалка-алгоритм для задач приближенного вычисления

Если дано выражение (например, $A(3.01; -2.98)$):

1. Введи функцию $f(x,y)$ (например, $x^2-y^2$).
    
2. Выбери удобные близкие целые точки $x_0, y_0$ (например, $x_0=3, y_0=-3$).
    
3. Найди малые приращения: $\Delta x = x - x_0$, $\Delta y = y - y_0$.
    
4. Найди частные производные $f'_x$ и $f'_y$ и вычисли их числовые значения в точке $(x_0, y_0)$.
    
5. Подставь всё в формулу: $f(x, y) \approx f(x_0, y_0) + f'_x(x_0,y_0)\Delta x + f'_y(x_0,y_0)\Delta y$.
